# Instalação

abra o cmd na pasta que esta o main.py e execute:
python -m pip install tkintermapview requests
python main.py

## Tecnologias

- Python 3
- Tkinter e [tkintermapview](https://github.com/TomSchimansky/TkinterMapView)
- Requests
- OSRM (rotas) e Telegram Bot API (envio)
- PyInstaller (geração do executável)
